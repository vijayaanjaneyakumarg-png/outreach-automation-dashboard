# Outreach Automation Dashboard

## Overview

This project is a proof-of-concept Outreach Automation Dashboard built using React.js, Express.js, and Axios.

The application allows users to:

* Enter a company domain
* View similar companies
* View contact information
* View email information
* Generate an outreach email preview
* Simulate the email sending workflow

## Tech Stack

### Frontend

* React.js
* Axios

### Backend

* Express.js
* Node.js

## Features

* Company domain input
* API communication between React and Express
* Similar companies display
* Contact information display
* Email information display
* Email preview generation
* Send Email simulation
* Statistics dashboard

## How to Run

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### Backend

```bash
cd backend
npm install
node server.js
```
